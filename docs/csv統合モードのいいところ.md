# CSV統合モード（Fusion Studio）完全ガイド

## 概要

複数のCSV/Excelファイルを統合し、商品データを分析・グループ化するための専用ツール。
せどり・転売ビジネスにおける価格調査・仕入れ判断を強力にサポートします。

---

## 主な機能

### 1. ファイル統合機能

#### 対応形式
- CSV（カンマ区切り、タブ区切り）
- Excel（.xlsx、.xls）
- 複数ファイルの一括読み込み

#### 統合方法
- **縦結合**: 複数ファイルのデータを縦に連結
- **横結合**: 複数ファイルのデータを横に連結

#### スマート機能
- **ヘッダー自動判定**: データにヘッダーがあるかを自動判定
- **ヘッダー自動予測**: ヘッダーがない場合、列パターンから自動生成
  - 例: `['ブランド', '商品コード', '商品名', '価格']`
- **重複行の自動除去**: 完全一致する行を自動で除去

---

### 2. グループ化機能

#### 商品名類似度グループ化
- レーベンシュタイン距離を使用した類似度計算
- 類似した商品名を自動でグループ化
- しきい値調整可能（デフォルト80%）

**例：**
```
「撥水ナイロンコート ブラック」
「撥水ナイロンコート ネイビー」
「撥水ナイロンコート」
→ 同一グループとして統合
```

#### 商品コードグループ化
- 商品コード（品番）での完全一致グループ化
- 同一品番の価格比較に最適

---

### 3. 列自動検出機能

データのパターンを分析して列の種類を自動判定：

| パターン | 判定結果 |
|---------|---------|
| `FRAMeWORK` など | ブランド名 |
| `22-020-220-6070` | 商品コード |
| 日本語テキスト | 商品名 |
| 数値（100以上） | 価格 |

#### 対応する列構成
- 3列: ブランド / 商品コード / 価格
- 4列: ブランド / 商品コード / 商品名 / 価格
- 5列以上: 自動パターン分析

---

### 4. グループ集計機能

グループ化後、以下の統計情報を自動計算：

| 項目 | 説明 |
|-----|------|
| 件数 | グループ内の商品数 |
| 最頻値価格 | 最も多い価格帯（1000円単位） |
| 商品コード | グループの代表的な商品コード |
| 価格帯 | 最低価格〜最高価格 |
| 追加日時 | 集計実行日時 |

---

### 5. 価格分析機能

#### ヒストグラム表示
- 価格分布をグラフで可視化
- どの価格帯に商品が集中しているか一目瞭然

#### 仕入れ判断サポート
- 最頻値価格: 市場の「相場」を把握
- 価格帯: 価格のばらつきを確認
- 件数: データの信頼性を判断

---

### 6. ストック機能

気になるグループをワンクリックでストック：

- ブランド名
- グループ名（商品名）
- 商品コード
- 価格情報（最頻値、価格帯）

→ 後から仕入れリストとして活用可能

---

### 7. エクスポート機能

統合・グループ化したデータを出力：

- **CSV形式**: Excel等で開ける
- **Excel形式**: そのまま編集可能

---

## 使い方

### 基本フロー

```
1. ファイルをドラッグ&ドロップ
   ↓
2. 「統合」ボタンをクリック
   ↓
3. 必要に応じてグループ化
   ↓
4. グループ集計で価格分析
   ↓
5. 気になる商品をストック
   ↓
6. データをエクスポート
```

### グループ化の選び方

| 目的 | 推奨グループ化 |
|-----|--------------|
| 同じ商品の価格比較 | 商品名類似度グループ化 |
| 同一品番の価格調査 | 商品コードグループ化 |
| 生データの確認 | グループ化なし |

## 技術仕様

### 類似度計算
- アルゴリズム: レーベンシュタイン距離
- 計算式: `(1 - 編集距離 / 最大文字数) × 100`

### 商品コード判定パターン
```
/^\d{2,}-\d{2,}-\d{2,}/
例: 22-020-220-6070
```

### 価格判定
- 最終列が100以上の数値 → 価格列
- カンマ、円記号は自動除去

## FAQ

**Q: ヘッダーがないデータでも使える？**
A: 自動で予測ヘッダーを生成します。

**Q: 商品コードが空欄の行がある場合は？**
A: 「-」と表示されます。グループ化には影響しません。

**Q: グループ化のしきい値は変更できる？**
A: 現在は80%固定です。

**Q: 大量のデータでも動く？**
A: ブラウザ上で動作するため、数万行程度まで対応。
