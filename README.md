## 🚀 PROFIT MATRIXとは？

メルカリの売れ筋商品データから、Yahoo!ショッピングで安く仕入れられる**利益商品を完全自動で発見**する次世代Webアプリケーション。

### ✨ 3つの革新的機能

1. **💰 Yahoo検索モード** - メルカリCSV → Yahoo自動検索 → 利益商品抽出
2. **📊 CSV統合モード** - 複数CSV結合 → クリーニング → グループ化 → 分析
3. **👥 外注先管理** - 利益商品をメール/LINEで一括送信

## 🎯 主要機能

### 💰 Yahoo検索モード

- **完全自動検索**: CSVアップロード → 商品検索 → 利益計算まで全自動
- **リアルタイム進捗表示**: 検索状況をライブ表示
- **利益率フィルター**: 40%以上の商品だけ抽出
- **在庫状況チェック**: 在庫切れ商品を自動除外
- **並び替え機能**: 利益額/利益率/価格で自動ソート
- **チェックボックス選択**: 気になる商品を一括管理（オーナー専用）
- **外注先送信**: 選択商品をメール/LINEで送信（オーナー専用）
- **見送り機能**:
  - 興味のない商品を見送り
  - localStorage永続化で再表示時も見送り状態を保持
  - 見送りクリアボタンで一括解除可能
- **ドラッグ&ドロップ対応**: ファイル選択が簡単

### 📊 CSV統合モード

#### 1. CSV結合機能
- **複数ファイル一括処理**: ドラッグ&ドロップで簡単アップロード
- **縦結合/横結合**: 2つの結合方法に対応
- **Excel対応**: .xlsx/.xlsファイルも読み込み可能
- **文字エンコーディング**: UTF-8/Shift-JIS自動検出
- **重複削除**: 重複行を自動削除
- **ストック機能**:
  - 処理済み商品をストックリストに保存
  - CSV保存・読み込み機能
  - 手動追加対応
  - 統合モード専用（Yahoo検索モードでは非表示）

#### 2. B列クリーニング
- 「〇〇様専用」パターン削除
- 価格情報削除（定価〇円、¥〇〇など）
- 商品状態削除（美品、新品、未使用など）
- 宣伝文句削除（人気、激安、限定など）
- 過剰な記号削除（★☆♪◆など）
- カスタムパターン対応

#### 3. ブランド処理
- **300+ブランド自動認識**
- A列に自動抽出
- 主要ブランド:
  - Deuxieme Classe
  - IENA
  - Spick and Span
  - PLAGE
  - Noble
  - など300+ブランド

#### 4. 商品グループ化
- **類似商品を自動統合**
- 色名を無視（Black, Navy, Grayなど）
- サイズを無視（S, M, L, XLなど）
- 年代を無視（2023, 2024など）
- 類似度調整（30%〜100%）
- グループごとに価格分布を表示
- 中央値/最頻値/平均値を自動算出

1. 商品画像から商品番号（例: 12020014）を取得

4. CSV統合モードでグループ化・分析

- ✅ オークファン不要（コスト削減）

### ログイン・認証関連

**Q: メール認証が届きません**
- 迷惑メールフォルダを確認してください

**Q: ログインできません**
- メールアドレスとパスワードが正しいか確認してください
- メール認証が完了しているか確認してください
- ブラウザのキャッシュをクリアしてください
- シークレットモード/プライベートブラウジングで試してください

**Q: パスワードを忘れました**
- ログイン画面の「パスワードを忘れた方」リンクをクリック
- メールアドレスを入力して送信
- 受信したメールからパスワードリセット

### APIキー関連

**Q: Yahoo Shopping APIキーが無効と表示されます**
- APIキーが正しいか確認してください（コピペ時の空白に注意）
- Yahoo!デベロッパーネットワークでアプリケーションが有効か確認
- 1日50,000リクエスト上限に達していないか確認
- 新しいAPIキーを取得して再設定してください

**Q: APIキーはどこに保存されますか？**
- ブラウザのlocalStorageに保存されます
- サーバーには送信されません
- デバイスごとに保存されるため、別デバイスでは再入力が必要です

### CSV・ファイル関連

**Q: CSVファイルがアップロードできません**
- ファイル形式が.csv/.xlsx/.xlsか確認してください
- ファイルサイズが大きすぎないか確認（推奨: 5MB以下）
- ファイルが破損していないか確認
- 別のブラウザで試してください

**Q: 文字化けが発生します**
- CSV統合モードで「文字エンコーディング」を「Shift-JIS」に変更
- Excelで保存する際は「CSV UTF-8（コンマ区切り）」を選択
- メモ帳で開いて文字コードを確認

**Q: 検索結果が0件です**
- CSVの列構成が正しいか確認（A列:ブランド, B列:商品名, D列:価格）
- 商品名が正確か確認（誤字・脱字がないか）
- 利益率フィルター（40%）が厳しすぎないか確認
- Yahoo!に在庫がない可能性があります

### 検索・機能関連

**Q: 検索が途中で止まります**
- インターネット接続を確認してください
- Yahoo APIのレート制限（1秒1リクエスト）により時間がかかります
- 100件の検索には約100秒かかります（正常動作）
- ブラウザを開いたままお待ちください

**Q: 見送りボタンが動きません**
- ブラウザのJavaScriptが有効か確認
- ブラウザのキャッシュをクリア
- ページを再読み込み（F5）
- 別のブラウザで試してください

**Q: 外注先管理が表示されません**
- オーナー専用機能です（メールアドレスに「komedorobouinuzini」が必要）
- 一般ユーザーには表示されません

### パフォーマンス関連

**Q: 動作が重いです**
- CSVデータが大きすぎる可能性があります（推奨: 2000行以下）
- ブラウザのタブを複数開きすぎていませんか？
- PCのメモリ不足の可能性があります
- Google Chromeの使用を推奨します
